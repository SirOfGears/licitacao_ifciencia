# licitacao_ifciencia
um script python usado para padronizar pedidos de objetos/serviços e facilitar a hora de os elencar.

**Baixe a biblioteca reportlab** 
\-> pip install reportlab

Clone ou baixe o repositório em sua máquina.

Abra o terminal na pasta onde o arquivo licitacao.py está salvo.

Execute o script com o comando:

Bash
python licitacao.py
Responda às solicitações interativas no terminal:

Nome do Servidor Responsável.

Quantidade de objetos/serviços a solicitar.

Nome e quantidade de cada item.

O arquivo PDF será gerado automaticamente na mesma pasta com a nomenclatura:

Licitacao_DD-MM-AAAA_HH-MM-SS.pdf.

-- Estrutura do Documento Gerado --
O PDF gerado contém a seguinte estrutura visual:

Cabeçalho: IFCIENCIA PODCAST - PVA.

Corpo do Texto: Declaração oficial citando o Servidor Responsável.

Lista Numerada de Itens: Objeto/serviço e quantidade solicitada.

Campos de Assinatura e Data: Espaço reservado para validação física do documento.
